# botik — заказы с Тильды в Telegram

Бот сидит в общей беседе (ты и Даня) и делает две вещи.

**1. Присылает заказы с Тильды** коротко, в стиле беседы:

```
Шуба M долями — 25 000
Зипка Тайно L долями — 7 000
Дане: 7 125 + 2 005 = 9 130
должен Дане всего: 23 006

🛒 Тильда #555 · Иван · +7999
🚚 СДЭК
себес 11 500 · комиссия 2 240 · прибыль 18 260 · мне 9 130
⏳ Не отправлен            [📦 Отправлено] [❌ Отмена]
```

**2. Понимает продажи, которые вы пишете в беседу руками**: «шуба Л с капюшоном долями»,
«2 тайно долями», «зипка тайно дернул переводом», «бомбер с промо 5%», «кружево 2000».
Бот ответит на такое сообщение, сколько с него Дане, запишет продажу в таблицу и даст
кнопку «❌ Отменить (ошибся)». Если похожий заказ уже пришёл с Тильды, бот сначала
спросит, не тот же ли это заказ, чтобы не посчитать его дважды.

На «Наликом 30к✅», «5к в долг», «скинул 12к» бот спросит «Записать как выплату Дане?» и
после кнопки уменьшит долг.

Ещё бот умеет:
- считать **прибыль бренда** (выручка − скидка − комиссия способа оплаты − себестоимость) и делить её 50/50;
- вести **учёт верхней одежды по размерам**: сколько продано, а если задан `stock`, то и остаток;
- если ответить (reply) на карточку заказа трек-номером, отмечать заказ отправленным;
- обновлять **онлайн-таблицу Google Sheets** на листах
  `Сводка` · `Заказы` · `Размеры` · `Отправка` (сверка «отправлено / не отправлено / просрочено») · `Выплаты Дане`;
- раз в день **напоминать** о неотправленных заказах.

## Команды в чате

| Команда | Что делает |
|---|---|
| `/pending` | не отправленные заказы (🔴 значит просрочен) |
| `/sizes` | верхняя одежда по размерам: продано / остаток |
| `/stats` | выручка, прибыль бренда, твоя доля и доля Дани, сколько скинуто, долг |
| `/paid 5000 [коммент]` | записать, что скинул Дане |
| `/ship 1234 [трек]` | отметить заказ отправленным |
| `/sync` | принудительно обновить таблицу |
| `/reload` | перечитать `products.yaml` |
| `/chatid` | показать id чата (для настройки) |

## Настройка

1. **Бот.** Создай бота в @BotFather, добавь его в чат с Даней и в BotFather отключи
   *Group Privacy* (`/setprivacy` → Disable), чтобы бот видел ответы с треками.
   Напиши в чате `/chatid` и запиши полученное число.
2. **Конфиг.** `cp .env.example .env` и заполни `BOT_TOKEN`, `CHAT_ID`, `TILDA_TOKEN`
   (доля Дани задаётся в `DANE_SHARE_PERCENT`, по умолчанию 50).
3. **Каталог.** `cp products.example.yaml products.yaml`. Для каждого товара укажи, как он
   называется в Тильде и в беседе (`match`), цену (`price`, нужна для продаж из чата без суммы),
   себестоимость (`cost`), является ли он верхней одеждой (`outerwear`) и, по желанию,
   стартовые остатки (`stock`). Там же настраиваются комиссии способов оплаты (`payments`).
4. **Google-таблица** (по желанию):
   - в Google Cloud создай сервисный аккаунт, включи *Google Sheets API*, скачай JSON-ключ как `service_account.json`;
   - создай пустую таблицу и выдай доступ «Редактор» email-у сервисного аккаунта;
   - id таблицы (кусок URL между `/d/` и `/edit`) запиши в `GOOGLE_SHEET_ID`.
5. **Запуск:** `docker compose up -d --build`, либо `pip install -r requirements.txt && python -m app.main`.
6. **Тильда.** В «Настройки сайта → Формы → Webhook» добавь URL
   `https://<твой-домен>/tilda?token=<TILDA_TOKEN>` и подключи его к форме корзины.
   Если включена онлайн-оплата, выбери отправку данных **после успешной оплаты**.
   Тильда шлёт тестовый запрос, на который бот отвечает `ok`. Нужен HTTPS, поэтому порт 8080
   поставь за nginx/Caddy или используй туннель (Cloudflare Tunnel и т.п.).

## Как считается

На каждую позицию:

```
выручка        = сумма позиции − доля скидки по промокоду (скидка делится пропорционально суммам)
комиссия       = выручка × % способа оплаты (долями 7, СБП 0.7, перевод/нал 0, карта 3.5 — правится в products.yaml;
                 продажа из чата без способа: 0; заказ с Тильды с нераспознанным способом: ACQUIRING_PERCENT)
себестоимость  = cost (для размера или default) × кол-во
прибыль бренда = выручка − комиссия − себестоимость
Дане           = прибыль бренда × DANE_SHARE_PERCENT % (по умолчанию 50%)
мне            = прибыль бренда − Дане
```

Если товар продан в минус, доля Дани тоже отрицательная, то есть убыток делится пополам.

Доставка в прибыль не входит, считается транзитом. Отменённые заказы не попадают в суммы и учёт размеров.
`Должны Дане` = всё начисленное Дане − всё записанное через `/paid`.

Если товара нет в каталоге, заказ всё равно приходит, но с пометкой «⚠️ нет в каталоге»,
и себестоимость по нему считается 0, так что прибыль завышена. Добавь товар в каталог и сделай `/reload`.
Размер берётся из опции Тильды «Размер»/«Size», а если её нет, то из названия товара.

Данные хранятся в SQLite (`data/orders.db`), таблица полностью пересобирается из неё,
поэтому правки руками в Google Sheets перезапишутся.

## Важно

- После запуска бота **не пишите в беседу продажи с сайта**: они придут сами. Если всё-таки
  напишете, бот заметит похожий заказ с Тильды за последние 3 дня и переспросит.
- Продажа из чата записывается, только если в сообщении есть товар из каталога **и** хоть
  какой-то признак продажи: способ оплаты, цена, размер, промо, количество или «витрина».
  Сообщения вроде «тайно закончились?» или просто «реквием» бот не трогает.
- Правка сообщения в Telegram на запись не влияет. Если ошиблись, жмите «❌ Отменить» и пишите заново.
