# botik — заказы с Тильды в Telegram

Бот сидит в общей беседе (ты и Даня) и присылает туда заказы с Тильды. Сообщения,
которые вы пишете в беседу сами, он не разбирает.

```
Шуба M долями — 25 000
Зипка Тайно L долями — 7 000
Дане: 7 125 + 2 005 = 9 130
должен Дане всего: 23 006

🛒 Тильда #555 · Иван · +7999
🚚 СДЭК
себес 11 500 · комиссия 2 240 · прибыль 18 260 · мне 9 130
⏳ Не отправлен            [📦 Отправлено] [❌ Отмена]
```

- **Отдал Дане его долю**: поставь любую реакцию на карточку заказа. Бот допишет
  «✅ отдано 06.10» и уменьшит долг. Снял реакцию, и заказ снова в долгах.
- **Прибыль бренда** = выручка − скидка − комиссия способа оплаты − себестоимость, делится 50/50.
- **Учёт верхней одежды по размерам**: сколько продано, а если задан `stock`, то и остаток.
- **Отправка**: кнопка «📦 Отправлено» или ответ (reply) на карточку трек-номером.
- **Онлайн-таблица Google Sheets** на листах
  `Сводка` · `Заказы` · `Размеры` · `Отправка` (сверка «отправлено / не отправлено / просрочено») · `Дане` (что отдано, что нет).
- **Напоминание** раз в день о неотправленных заказах.

## Команды в чате

| Команда | Что делает |
|---|---|
| `/pending` | не отправленные заказы (🔴 значит просрочен) |
| `/sizes` | верхняя одежда по размерам: продано / остаток |
| `/stats` | выручка, прибыль бренда, твоя доля и доля Дани, сколько отдано, долг |
| `/dolg` | за какие заказы ещё не отдал Дане |
| `/ship 1234 [трек]` | отметить заказ отправленным |
| `/sync` | принудительно обновить таблицу |
| `/reload` | перечитать `products.yaml` |
| `/chatid` | показать id чата и твой id (для настройки) |

## Настройка

1. **Бот.** Создай бота в @BotFather, добавь его в чат с Даней и **сделай администратором**:
   без этого Telegram не присылает боту реакции. В BotFather отключи *Group Privacy*
   (`/setprivacy` → Disable), чтобы бот видел ответы с треками.
   Напиши в чате `/chatid` и запиши оба числа: id чата и свой id.
2. **Конфиг.** `cp .env.example .env` и заполни `BOT_TOKEN`, `CHAT_ID`, `TILDA_TOKEN`
   (доля Дани задаётся в `DANE_SHARE_PERCENT`, по умолчанию 50). В `PAYER_IDS` впиши свой id,
   чтобы «отдал Дане» засчитывались только твои реакции, а не Данины.
3. **Каталог.** `cp products.example.yaml products.yaml`. Для каждого товара укажи, как он
   называется в Тильде (`match`), себестоимость (`cost`), является ли он верхней одеждой
   (`outerwear`) и, по желанию, стартовые остатки (`stock`). Там же настраиваются комиссии
   способов оплаты (`payments`).
4. **Google-таблица** (по желанию):
   - в Google Cloud создай сервисный аккаунт, включи *Google Sheets API*, скачай JSON-ключ как `service_account.json`;
   - создай пустую таблицу и выдай доступ «Редактор» email-у сервисного аккаунта;
   - id таблицы (кусок URL между `/d/` и `/edit`) запиши в `GOOGLE_SHEET_ID`.
5. **Запуск:** `docker compose up -d --build`, либо `pip install -r requirements.txt && python -m app.main`.
6. **Тильда.** В «Настройки сайта → Формы → Webhook» добавь URL
   `https://<твой-домен>/tilda?token=<TILDA_TOKEN>` и подключи его к форме корзины.
   Если включена онлайн-оплата, выбери отправку данных **после успешной оплаты**.
   Тильда шлёт тестовый запрос, на который бот отвечает `ok`. Нужен HTTPS, поэтому порт 8080
   поставь за nginx/Caddy или используй туннель (Cloudflare Tunnel и т.п.).

## Как считается

На каждую позицию:

```
выручка        = сумма позиции − доля скидки по промокоду (скидка делится пропорционально суммам)
комиссия       = выручка × % способа оплаты (долями 7, СБП 0.7, карта 3.5 — правится в products.yaml;
                 нераспознанный способ: ACQUIRING_PERCENT)
себестоимость  = cost (для размера или default) × кол-во
прибыль бренда = выручка − комиссия − себестоимость
Дане           = прибыль бренда × DANE_SHARE_PERCENT % (по умолчанию 50%)
мне            = прибыль бренда − Дане
```

Если товар продан в минус, доля Дани тоже отрицательная, то есть убыток делится пополам.

Доставка в прибыль не входит, считается транзитом. Отменённые заказы не попадают в суммы и учёт размеров.
`Должны Дане` = сумма доли Дани по заказам, на которых нет твоей реакции.

Если товара нет в каталоге, заказ всё равно приходит, но с пометкой «⚠️ нет в каталоге»,
и себестоимость по нему считается 0, так что прибыль завышена. Добавь товар в каталог и сделай `/reload`
(уже пришедшие заказы не пересчитываются).
Размер берётся из опции Тильды «Размер»/«Size», а если её нет, то из названия товара.

Данные хранятся в SQLite (`data/orders.db`), таблица полностью пересобирается из неё,
поэтому правки руками в Google Sheets перезапишутся.
