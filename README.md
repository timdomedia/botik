# botik — заказы с Тильды в Telegram

Бот сидит в общей беседе (ты и Даня) и присылает туда заказы с Тильды. Сообщения,
которые вы пишете в беседу сами, он не разбирает.

```
Шуба M долями — 25 000
Зипка Тайно L долями — 7 000
Дане: 7 125 + 2 005 = 9 130
должен Дане всего: 23 006

🛒 Тильда #555 · Иван · +7999
🚚 СДЭК
себес 11 500 · комиссия 2 240 · прибыль 18 260 · мне 9 130
⏳ Не отправлен            [📦 Отправлено] [❌ Отмена]
```

- **Отдал Дане его долю**: поставь любую реакцию на карточку заказа. Бот допишет
  «✅ отдано 06.10» и уменьшит долг. Снял реакцию, и заказ снова в долгах.
- **Прибыль бренда** = выручка − скидка − комиссия способа оплаты − себестоимость, делится 50/50.
- **Учёт верхней одежды по размерам**: сколько продано, а если задан `stock`, то и остаток.
- **Отправка**: кнопка «📦 Отправлено» или ответ (reply) на карточку трек-номером.
- **Онлайн-таблица Google Sheets** на листах
  `Сводка` · `Заказы` · `Размеры` · `Отправка` (сверка «отправлено / не отправлено / просрочено») · `Дане` (что отдано, что нет).
- **Напоминание** раз в день о неотправленных заказах.

## Команды в чате

| Команда | Что делает |
|---|---|
| `/pending` | не отправленные заказы (🔴 значит просрочен) |
| `/sizes` | верхняя одежда по размерам: продано / остаток |
| `/stats` | выручка, прибыль бренда, твоя доля и доля Дани, сколько отдано, долг |
| `/dolg` | за какие заказы ещё не отдал Дане |
| `/ship 1234 [трек]` | отметить заказ отправленным |
| `/sync` | принудительно обновить таблицу |
| `/cost Шуба 9000` | себестоимость товара (`/cost Шуба 9500 XL` — для размера); неотданные заказы пересчитываются |
| `/outer Шуба` | считать товар верхней одеждой по размерам (`/outer Шуба нет` — убрать) |
| `/catalog` | товары, себестоимость и что ещё без неё |
| `/setup` | привязать бота к этому чату, а тебя — как того, кто отдаёт Дане |
| `/chatid` | показать id чата и твой id |

## Установка на VPS (Aeza, рядом с tg-finance)

### 1. Бот `@splitfinance_bot`: чистый старт
На этом боте раньше жил проект GULF SPLIT (Vercel + мини-апп). Чтобы от него ничего не осталось:

1. **Новый токен.** В @BotFather: `/mybots` → `@splitfinance_bot` → `API Token` → **Revoke current token**.
   Старый токен перестаёт работать везде, где он ещё прописан, и старый проект больше
   не сможет ни читать, ни писать от имени бота. Новый токен впиши в `.env` как `BOT_TOKEN`.
2. **Мини-апп.** В @BotFather: `/myapps` → приложение GULF SPLIT → **Delete**.
3. **Group Privacy.** В @BotFather: `Bot Settings` → `Group Privacy` → **Turn off**,
   чтобы бот видел ответы с треками.
4. **Остальное бот чистит сам при запуске**: снимает старый вебхук и выкидывает накопившиеся
   старые сообщения, удаляет старые команды, возвращает кнопку меню вместо мини-аппа,
   ставит новое описание и имя из `BOT_NAME` (юзернейм `@splitfinance_bot` остаётся).
5. Добавь бота в чат с Даней и **сделай администратором**: без этого Telegram не присылает
   боту реакции. Права можно снять все, нужен сам статус админа.

### 2. Установка одной командой
Зайди на сервер (`ssh root@<ip>`) и выполни:
```bash
curl -fsSL https://raw.githubusercontent.com/timdomedia/botik/claude/tilda-telegram-orders-bot-iplflz/install.sh | bash
```
Скрипт:
- поставит Docker, если его нет, и скачает бота в `/opt/botik`;
- спросит новый токен (и проверит его в Telegram), домен tg-finance и считать ли налог 6%;
- сам придумает секрет для Тильды и найдёт свободный порт;
- запустит бота и подключит `https://<домен>/tilda` в nginx: правит только https-блок этого домена,
  делает резервную копию и откатывает правку, если `nginx -t` ругается;
- проверит адрес снаружи и напечатает готовую ссылку для Тильды.

### 3. В Telegram и Тильде
1. Добавь бота в чат с Даней, сделай администратором и напиши в чате **`/setup`**.
   Бот запомнит этот чат, а тебя — как того, чьи реакции значат «отдал Дане».
   Заказы, пришедшие до `/setup`, он пришлёт сразу после.
2. Тильда → «Настройки сайта → Формы → Webhook» → ссылка из конца установки → подключи к форме корзины.
   Если включена онлайн-оплата, выбери отправку **после успешной оплаты**. Вебхук tg-finance не трогай.
3. Себестоимость — прямо в чате: `/cost Шуба 9000`, для размера `/cost Шуба 9500 XL`.
   Верхняя одежда по размерам: `/outer Шуба`. Список: `/catalog`.
   Если пришёл заказ с незнакомым товаром, на карточке будет подсказка с готовой командой `/cost`.

### 4. Google-таблица (по желанию)
- в Google Cloud создай сервисный аккаунт, включи *Google Sheets API*, скачай JSON-ключ
  и положи на сервер как `/opt/botik/service_account.json`;
- создай пустую таблицу и выдай доступ «Редактор» email-у сервисного аккаунта;
- id таблицы (кусок URL между `/d/` и `/edit`) запиши в `/opt/botik/.env` как `GOOGLE_SHEET_ID`,
  затем `cd /opt/botik && docker compose up -d`.

### Обновление
Запусти ту же команду установки ещё раз. Настройки, база (`/opt/botik/data/orders.db`) и каталог сохраняются.
Логи: `cd /opt/botik && docker compose logs -f`.

## Как считается

На каждую позицию:

```
выручка        = сумма позиции − доля скидки по промокоду (скидка делится пропорционально суммам)
комиссия       = выручка × % способа оплаты (долями 7, СБП 0.7, карта 3.5 — правится в products.yaml;
                 нераспознанный способ: ACQUIRING_PERCENT)
себестоимость  = из /cost (для размера или общая) × кол-во
налог          = выручка × TAX_PERCENT % (по умолчанию 0, для УСН 6% поставь 6)
прибыль бренда = выручка − комиссия − налог − себестоимость
Дане           = прибыль бренда × DANE_SHARE_PERCENT % (по умолчанию 50%)
мне            = прибыль бренда − Дане
```

Если товар продан в минус, доля Дани тоже отрицательная, то есть убыток делится пополам.

Доставка в прибыль не входит, считается транзитом. Отменённые заказы не попадают в суммы и учёт размеров.
`Должны Дане` = сумма доли Дани по заказам, на которых нет твоей реакции.

Если товара нет в каталоге, заказ всё равно приходит, но с пометкой «⚠️ нет себестоимости»,
и себестоимость по нему считается 0, так что прибыль завышена. На карточке будет готовая команда:
`/cost <товар> <сумма>`. После неё все заказы, за которые Дане ещё не отдано, пересчитаются
(уже отданные не меняются, чтобы не поехали суммы, которые ты отдал).

Данные хранятся в SQLite (`data/orders.db`), таблица полностью пересобирается из неё,
поэтому правки руками в Google Sheets перезапишутся.
