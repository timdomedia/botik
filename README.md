# botik — заказы с Тильды в Telegram

Бот принимает заказы с Тильды по вебхуку и присылает их в общий чат (ты и Даня):

- **карточка заказа**: клиент, доставка, товары с размерами, сумма;
- **«💸 Дане»**: сколько скинуть Дане по каждому товару и итог;
- **чистая прибыль** по заказу: выручка − скидка − эквайринг − Дане − расходы;
- **кнопки «📦 Отправлено» / «❌ Отмена»**, а если ответить (reply) на карточку трек-номером, заказ станет отправленным с этим треком;
- **учёт верхней одежды по размерам**: сколько продано, а если задан `stock`, то и остаток;
- **онлайн-таблица Google Sheets**, которая обновляется сама на листах:
  `Сводка` · `Заказы` · `Размеры` · `Отправка` (сверка «отправлено / не отправлено / просрочено») · `Выплаты Дане`;
- **ежедневное напоминание** в чат о неотправленных заказах.

## Команды в чате

| Команда | Что делает |
|---|---|
| `/pending` | не отправленные заказы (🔴 значит просрочен) |
| `/sizes` | верхняя одежда по размерам: продано / остаток |
| `/stats` | выручка, чистая, сколько начислено и скинуто Дане, долг |
| `/paid 5000 [коммент]` | записать, что скинул Дане |
| `/ship 1234 [трек]` | отметить заказ отправленным |
| `/sync` | принудительно обновить таблицу |
| `/reload` | перечитать `products.yaml` |
| `/chatid` | показать id чата (для настройки) |

## Настройка

1. **Бот.** Создай бота в @BotFather, добавь его в чат с Даней и в BotFather отключи
   *Group Privacy* (`/setprivacy` → Disable), чтобы бот видел ответы с треками.
   Напиши в чате `/chatid` и запиши полученное число.
2. **Конфиг.** `cp .env.example .env` и заполни `BOT_TOKEN`, `CHAT_ID`, `TILDA_TOKEN`.
3. **Каталог.** `cp products.example.yaml products.yaml`. Для каждого товара укажи, как узнать его
   в заказе (`match`: артикул или кусок названия), сколько скидываешь Дане (`dane`, можно по размерам),
   прочие расходы (`cost`), является ли он верхней одеждой (`outerwear`) и, по желанию, стартовые остатки (`stock`).
4. **Google-таблица** (по желанию):
   - в Google Cloud создай сервисный аккаунт, включи *Google Sheets API*, скачай JSON-ключ как `service_account.json`;
   - создай пустую таблицу и выдай доступ «Редактор» email-у сервисного аккаунта;
   - id таблицы (кусок URL между `/d/` и `/edit`) запиши в `GOOGLE_SHEET_ID`.
5. **Запуск:** `docker compose up -d --build`, либо `pip install -r requirements.txt && python -m app.main`.
6. **Тильда.** В «Настройки сайта → Формы → Webhook» добавь URL
   `https://<твой-домен>/tilda?token=<TILDA_TOKEN>` и подключи его к форме корзины.
   Если включена онлайн-оплата, выбери отправку данных **после успешной оплаты**.
   Тильда шлёт тестовый запрос, на который бот отвечает `ok`. Нужен HTTPS, поэтому порт 8080
   поставь за nginx/Caddy или используй туннель (Cloudflare Tunnel и т.п.).

## Как считается

На каждую позицию:

```
выручка   = сумма позиции − доля скидки по промокоду (скидка делится пропорционально суммам)
эквайринг = выручка × ACQUIRING_PERCENT %
Дане      = dane (для размера или default) × кол-во
расходы   = cost × кол-во
чистая    = выручка − эквайринг − Дане − расходы
```

Доставка в прибыль не входит, считается транзитом. Отменённые заказы не попадают в суммы и учёт размеров.
`Должны Дане` = всё начисленное Дане − всё записанное через `/paid`.

Если товара нет в каталоге, заказ всё равно приходит, но с пометкой «⚠️ нет в каталоге», и Дане по нему 0.
Размер берётся из опции Тильды «Размер»/«Size», а если её нет, то из названия товара.

Данные хранятся в SQLite (`data/orders.db`), таблица полностью пересобирается из неё,
поэтому правки руками в Google Sheets перезапишутся.
